第一章：建模與數值方法概論

數值方法是將工程與科學問題轉換為電腦可執行的算術與邏輯運算步驟。

解析解 (Analytical Solution)

利用微積分求得精確的閉式解 (Closed-form Solution)。

數值解 (Numerical Solution)

利用有限差分與迭代程序獲得極度接近真值的近似解。

案例解析：蹦極跳者自由落體

當運動達到平衡時，系統趨於穩態，終端速度表示為 $v_t$。

微分方程模型：
$$\frac{dv}{dt} = g - \frac{c_d}{m}v^2$$

解析解 (Analytical Solution)

利用微積分求得精確閉式解：

$$v(t) = \sqrt{\frac{gm}{c_d}}\tanh\left(\sqrt{\frac{gc_d}{m}}t\right)$$

數值解 (Euler's Method)

利用有限差分近似斜率：

$$v_{i+1} = v_i + \left(g - \frac{c_d}{m}v_i^2\right)\Delta t$$
💡 數值估算核心通則： $$\text{New Value} = \text{Old Value} + \text{Slope} \times \text{Step Size}$$

第四章：捨入誤差與截斷誤差

相對誤差與停止準則

近似相對誤差百分比 $\varepsilon_a$ 計算公式：

$$\varepsilon_a = \left\vert{} \frac{x_r^{\text{new}} - x_r^{\text{old}}}{x_r^{\text{new}}} \right\vert{} \times 100\%$$

當滿足以下條件時停止迭代：

$$\varepsilon_a < \varepsilon_s = (0.5 \times 10^{2-n})\%$$

第五與六章：求解非線性根

二分法 (Bisection)

包圍法，將區間對半劃分：

$$x_r = \frac{x_l + x_u}{2}$$

牛頓-拉夫生法 (Newton-Raphson)

開放法，利用切線斜率迭代：

$$x_{i+1} = x_i - \frac{f(x_i)}{f'(x_i)}$$

第九章：高斯消去法 (Gauss Elimination)

求解線性系統 $A \mathbf{x} = \mathbf{b}$ 的標準兩階段步驟：

  1. 向前消去 (Forward Elimination)：將係數矩陣轉換為上三角矩陣。
  2. 向後代換 (Back Substitution)：從最後一個變數依序求解： $$\mathbf{x}_i = \frac{b_i - \sum_{j=i+1}^n a_{ij}x_j}{a_{ii}}$$
